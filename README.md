# صيدليات الثورة — Web Release

نسخة ويب قابلة للنشر مبنية بـ Node.js بدون إطار خلفي إضافي.

## التشغيل المحلي
1. ثبّت Node.js 20+.
2. افتح CMD داخل المجلد.
3. شغّل `npm start`.
4. افتح `http://localhost:3000`.

## حساب المالك الافتراضي
- البريد: `elthawrapharmacy@gmail.com`
- كلمة المرور الافتراضية: `admin123`

**غيّر كلمة المرور قبل أي نشر عام.** يمكن ضبطها أول مرة عبر `DEFAULT_OWNER_PASSWORD` قبل إنشاء قاعدة البيانات.

## البريد الإلكتروني
التحقق بالبريد يدعم Resend عبر:
- `RESEND_API_KEY`
- `MAIL_FROM`

بدون المفتاح سيظهر رمز التحقق في نافذة تشغيل السيرفر فقط، وهذا مناسب للاختبار وليس للنشر العام.

## البيانات
البيانات في `data/db.json` والمستندات الحساسة في `data/documents/`. لا تضع هذا المجلد خلف رابط عام مباشر.

## ما تم تضمينه
- تسجيل العملاء والتحقق بالبريد
- حسابات CUS/EMP
- فروع ومخزون ومنتجات
- سلة وطلبات وحالات وتعديل قبل انتهاء المهلة
- الدفع النقدي أو المحفظة الداخلية فقط، بدون بوابة دفع إلكترونية
- محفظة بإضافـة أموال كصلاحية منفصلة وسجل تدقيق
- موظفون ومسمّيات وظيفية وصلاحيات منفصلة
- طلب مستند من العميل ورفع/مراجعة المستندات
- حضور مع Geofence عند تسجيل الدخول/الخروج
- عقود وفروع وإعلانات وتقارير وسجل تدقيق
- كوبونات خصم قابلة للإدارة من لوحة التحكم: نسبة/مبلغ، حد أدنى، حد استخدام، مدة، فرع/منتجات/عملاء، تشغيل وإيقاف
- إشعارات داخل الموقع
- حماية المستندات وعدم تقديمها كملفات عامة

## قبل النشر العام
- غيّر كلمة مرور المالك.
- اضبط HTTPS من الاستضافة.
- اضبط `RESEND_API_KEY` و`MAIL_FROM`.
- استخدم تخزين/نسخ احتياطي موثوق لقاعدة البيانات والمستندات.
- لا توجد بوابة دفع إلكترونية في هذه النسخة؛ المحفظة رصيد داخلي للصيدلية والدفع النقدي متاح.
- راجع متطلبات حماية بيانات المرضى/الوصفات والعقود قبل التشغيل التجاري.
